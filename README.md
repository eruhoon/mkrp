# mkrp (Make Ren'Py Portable) 🎮

`mkrp` is a launcher template and porting toolkit designed to run **Ren'Py visual novel games** smoothly and reliably on Linux ARM64-based retro handheld consoles (e.g., RG VITA PRO, RG40XXH, RG DS / running ROCKNIX, Knulli, ArkOS) within the **PortMaster** ecosystem.

---

## 🌟 Features

1. **PortMaster Standard Ren'Py Runtime Integration**:
   - Provides a universal launcher script (`mkrp.sh`) and metadata (`port.json`) compliant with the official PortMaster Ren'Py runtime specifications.
2. **Ren'Py 8 Runtime Backward Compatibility Layer (Compat Polyfills)**:
   - **Python 2 ➔ Python 3 Migration Safeguards**: Prevents crashes caused by legacy (Ren'Py 7) comparisons in stats/affection values (`builtins.cmp`, comparisons with `None`).
3. **Handheld Optimization**:
   - Dynamic image cache tuning to prevent Out-Of-Memory (OOM) crashes on low-spec handhelds (1GB–2GB RAM).
   - Built-in gamepad and analog stick virtual mouse mapping powered by `gptokeyb`.
4. **Asset Lightweighting & Redirection Guide**:
   - Guidance on converting unsupported image formats (e.g., AVIF) into WebP/PNG and loading them on the fly via patch archives.

## 📁 Project Structure

### 1. Source Repository

```text
mkrp/
├── template/              # PortMaster distribution template
│   ├── mkrp.sh            # PortMaster device launcher script
│   ├── port.json          # PortMaster metadata and runtime configuration
│   └── keymap.gptk        # gptokeyb gamepad/virtual mouse mapping
├── scripts/               # Build and utility scripts
│   ├── build.mjs          # PortMaster zip packaging script
│   └── clean.mjs          # Clean dist build directory
├── HOW_TO_USE.md          # Hardware installation and device setup guide
├── package.json           # Node.js project manifest
└── README.md              # Project documentation
```

### 2. Distribution Package Structure (PortMaster `ports/`)

Extracted structure of `dist/mkrp-v*.zip` generated by `npm run build`:

```text
roms/ports/ (or storage/roms/ports/)
├── mkrp.sh                # Game launcher script
└── mkrp/                  # Main game directory
    ├── port.json          # Port metadata
    ├── keymap.gptk        # Control mapping configuration
    ├── game/              # ⭐️ User game assets (*.rpa, *.rpyc) and patch scripts
    └── saves/             # Save data directory
```

## 🚀 Quick Start

### 1. Build the PortMaster Package

```bash
npm install
npm run build
```

Once the build finishes, the archive will be generated at `dist/mkrp-v<version>.zip`.

### 2. Device Installation & Running Games

Extract the generated package into the `ports/` directory on your device's SD card, and copy the contents of your Ren'Py game's `game/` folder into `mkrp/game/`.

> [!TIP]
> For step-by-step installation instructions and control mapping guides, refer to [HOW_TO_USE.md](HOW_TO_USE.md).
